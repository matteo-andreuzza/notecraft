# NoteCraft roadmap: milestones and what's next

> **Last reviewed:** 2026-10-15 · **Last updated:** 2026-10-15 · **Change:** major (M1 done) · **Target:** Microsoft OneNote for Microsoft 365, desktop for Windows

Forward-looking plan; details and rationale are in [`plan.md`](plan.md).

## Current focus

1. M2: Insert and Draw (tables, pictures, files, ink), the rich clipboard, the canvas details and
   the missing dialogs (see [`gaps.md`](gaps.md), items 2–8).
2. Keep the two parity numbers honest: rows move to `wired` only with a test, to `verified` only
   with a `// parity:` test that pins the documented behaviour.
