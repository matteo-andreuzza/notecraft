This is the assessment page (the siblings call it `target-app-parity.md`). Every number here is
computed by `cargo xtask parity` from [`parity-catalog.md`](parity-catalog.md) — the inventory of
OneNote's ribbon controls, context-menu items, backstage entries, keyboard shortcuts, options,
documented behaviours, file-format constructs and UI surfaces — joined with the command registry
and the tests. **Wiring is not parity**: a row is *wired* when a working command or control
exists for it, and *verified* only when a test pins its documented behaviour.
